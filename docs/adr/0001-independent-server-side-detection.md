# 無頭瀏覽器獨立偵測，而非延伸既有瀏覽器擴充功能

使用者已有一套用起來滿意的 Chrome 擴充功能（chandler-stimson/live-stream-downloader）做串流偵測。我們考慮過直接延伸該擴充功能，讓它把偵測到的網址送到伺服器下載，但這樣每台要用的裝置都得先裝好擴充功能。為了讓工具能「任何裝置只要丟網址就能用」，改為讓伺服器用無頭瀏覽器（Playwright）獨立重做一套偵測邏輯（比照原專案的網路請求攔截 + DOM/播放器內省手法），與現有擴充功能完全獨立、互不依賴。

## Consequences

未來若原專案的偵測手法改進，不會自動跟著擴充功能更新，需要手動同步移植。
